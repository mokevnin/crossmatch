# CrossMatch

**Бот, который подбирает каналы для взаимного пиара в Telegram.**

Не каталог и не доска объявлений: CrossMatch сам предлагает, с кем стоит обменяться, а вам остаётся нажать «Интересно».

[Открыть @crossmatch_bot](https://t.me/crossmatch_bot)

> Проект в разработке.

## Как это работает

1. **Добавьте канал.** Бот проверяет, что вы админ, и спрашивает тематику, язык и формат обмена.
2. **Получите подборку.** Несколько каналов с похожей тематикой и сопоставимым охватом, у каждого сказано, почему он подходит.
3. **Нажмите «Интересно».** Контакт открывается только при взаимном интересе. Если второй не ответил, вы не увидите отказа.

## Чем отличается

- **Подбор вместо каталога.** Никакого ручного поиска и переписки с десятками незнакомых админов.
- **Охват, а не подписчики.** Накрученные каналы отсеиваются по реальному охвату поста.
- **Без сайта и регистрации.** Всё внутри Telegram.
