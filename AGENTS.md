# AGENTS.md

## Project overview

CrossMatch is a Telegram bot that matches channel admins for mutual promotion. It is a Go program on PostgreSQL, with SQL written by hand and Go generated by sqlc. `README.md` is also the public landing page, so it is written for visitors.

## Commands

- `mise install` installs the pinned toolchain and the git hooks.
- `mise run check` runs every check, the same set CI runs. A change is done when it passes.
- `mise run fix` applies the automatic fixes.
- `mise run generate` regenerates `internal/store` after a change to `migrations/` or `queries/`.

## Rules

Each rule is backed by a check in `mise run check`.

- Never edit `internal/store` by hand. Change the SQL in `migrations/` or `queries/` and run `mise run generate` (`sqlc diff` fails on a stale copy).
- A migration must pass squawk. On a table that already holds rows, create indexes with `CREATE INDEX CONCURRENTLY` in a migration marked `-- +goose NO TRANSACTION`.
- Package boundaries live in `easement.yml`. A violation prints the rule's reason: read it before adding a baseline entry.
- Do not disable a lint rule or a hook to get a change through. An exception is narrow (one path and one rule), carries a reason, and needs a human decision.
- The repository is public. Never commit credentials: the bot's Telegram credential comes from the `BOT_TOKEN` environment variable, and `.env.example` holds empty placeholders only (betterleaks scans the tree and the history).
- Write commit messages and code comments in English.
